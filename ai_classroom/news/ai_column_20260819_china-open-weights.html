開源模型「開」的是什麼 · 資料截至 2026-08-19

中國模型確實追上來了，但他們公開的是次一階的權重， 最強的那一顆留在自家 API 上收錢。

篇幅10 節 · 8 圖 · 8 表

上週向主管報告模型評比時出現一個問題：排行榜前段班有一半是中國團隊，而且都說自己是「開源」的，那他們靠什麼賺錢？如果模型可以免費下載，為什麼還會有人付錢？如果他們真的在做慈善，這件事對我們有什麼影響？

這篇專欄用一份完整的模型評測資料回答這三個問題。做法是：把「開源」這個詞拆開來看——一個模型從無到有要經過好幾道工序，被稱為開源的模型究竟公開了哪幾道、留下哪幾道；再看這些公司的財報與定價，確認錢實際上從哪裡進來；最後推估在「本公司使用 Azure、不採用中國模型」的前提下，還有哪些間接影響會繞過這個前提發生。

全篇的數字都來自兩個公開資料源，抓取日期為 2026-08-19。每一節的結論都可以往回追到圖表與表格，看到不懂的專有名詞，內文括號裡都附了白話說明，較長的說明放在灰色按鈕的彈出框裡。

問題一
他們「開」的到底是什麼

答案：只開了權重這一層，而且多半是次一階的版本。訓練資料、資料配方、訓練方法都沒有公開。見第 2、3、5 節。

問題二
那他們靠什麼收錢

答案：雲服務、私有化部署、授權金三條路，沒有一條靠賣權重。權重的角色是導流與卡位。見第 8 節。

問題三
對我們有什麼影響

答案：中國模型已經在 Azure 目錄裡、由微軟直接銷售。「不使用」目前沒有任何採購摩擦擋得住。見第 9 節。

技術面

「開源」在模型產業不是一個開關，而是八個面向各自的程度。 目前八項幾乎全公開的模型，能力最高只到 17.4 分； 能力 50 分以上的模型，公開程度最高只到 44.4 分。兩群沒有交集。

商業面

九家公司的收入都不是來自權重本身，而是雲服務、私有化部署與授權金。 釋出權重的用途是讓開發者先用起來，再把需要穩定、需要規模、需要保固的客戶導回付費的託管服務。

對我們

不必急著判斷「中國模型能不能用」。先確認三件事： Azure 目錄裡的模型有沒有國別控制項、委外廠商的 AI 底層是誰的權重、 以及選型驗收有沒有自己的題組，而不是引用外部榜單。

02

先把名詞講清楚：一個模型分成四層

這一節是後面所有討論的基礎，五分鐘讀完

新聞裡的「開源模型」，指的幾乎都是權重可以下載這一件事。權重是模型訓練完成之後留下的一大包參數檔，拿到它就可以在自己的機房裡跑推論，也可以再做微調。但一個模型從無到有，權重只是最後一層產出。

把四層攤開之後，「開源」這個詞的模糊之處就很清楚了：目前所有被稱為開源的中國模型，公開的都是第一層。第二層到第四層——用什麼資料訓練、資料怎麼配比與清理、訓練與後訓練的方法——沒有一家完整公開。這代表外界能複製的是「使用」，不是「重建」：你可以拿它來跑，但你無法自己做出一顆一樣的，也無法查證它是用什麼資料學出來的。

一個模型的四層，以及「開源」開的是哪一層 由下而上是製作順序，由上而下是公開的順序
第 4 層 · 權重
訓練完的參數檔

幾百 GB 的數字檔案，是模型「學完之後的樣子」。下載它就能在自有機房跑，也能拿自己的資料再微調。 中國廠商公開的就是這一層，而且多半是次一階的版本——最強的那一顆通常只在自家 API 上。

公開
第 3 層 · 後訓練方法
怎麼「調教」出來的

預訓練完的模型還不會好好回話，要再用人類偏好與強化學習調整。這一段的做法差異，是同樣大小的模型好不好用的關鍵。 公開的多半只有一篇技術報告，不含實際的資料與參數。

多為未公開
第 2 層 · 資料配方
資料怎麼挑、怎麼配比

程式碼佔幾成、中文佔幾成、怎麼去重複與過濾。這是各家最不願意講的部分， 因為它幾乎等於整個訓練流程的商業機密。

未公開
第 1 層 · 訓練資料
原始的訓練語料

模型讀過的所有文字。不公開的直接後果是：無法查證版權來源，也無法查證有沒有讀過不該讀的東西。 對金融業而言，這一層的不透明才是法遵上真正需要處理的部分。

未公開
拿到權重，你可以
  • · 在自有機房執行，資料不出公司
  • · 用自己的資料微調，做成專用模型
  • · 不受單一供應商的價格與停售影響
拿到權重，你仍然不能
  • · 知道它讀過什麼資料、有沒有版權問題
  • · 自己重做一顆同等的模型
  • · 假設它跟託管版一樣強（多半是次一階的版本）
三個詞的差別，常被混用
說法實際意思本篇怎麼稱呼
開源（Open Source）軟體業的原意：原始碼、授權、可修改可再散布三者齊備。模型很少符合。本篇不使用這個詞
開放權重（Open Weights）只有權重檔可下載，訓練資料與方法不公開。目前絕大多數所謂「開源模型」屬於這一類。權重有公開
閉源（Closed）只能透過 API 呼叫，權重不外流。不公開

Artificial Analysis 進一步把「公開程度」拆成八個面向評分，不採二分法。

03

證據一：公開得愈完整的模型，能力愈不強

303 個模型的分布，右上角是空的

第一個要檢查的是最常聽到的說法——「中國開源模型已經追平最強的閉源模型」。這句話要成立，必須存在一顆既完整公開、又進入第一梯隊的模型。資料顯示目前沒有。

把 303 個同時有「公開程度」與「能力分數」的模型畫成一張散點圖，橫軸愈往右代表公開得愈完整，縱軸愈往上代表模型愈強。分布呈現一個反 L 形：右上角那一格是空的。換句話說，公開得最完整的那批模型（多為研究機構釋出的模型），能力集中在低分區；而能力進入前段的模型，公開程度都停在 30 到 50 分之間——也就是「只給權重，不給資料與方法」的那一類。

這裡要特別說明統計上的讀法，避免推論過頭。整體的等級相關係數是 -0.30（Spearman 相關，衡量兩個排名的一致程度，−1 到 1 之間，0 代表沒有關係），屬於弱相關。所以不能說「愈公開就愈弱」。本節能成立的敘述只有一句：截至 2026-08-19，「八項全公開」與「能力進入前段」這兩件事，還沒有同時出現在同一顆模型上。這是分布邊界的描述，不是因果關係。

04

證據二：差距有多大，要看你考的是哪一張考卷

同一批模型，兩張考卷的差距差了十倍

第二個要檢查的是「差距是否已經收斂」。這個問題沒有單一答案，因為答案完全取決於引用哪一張考卷。

GPQA（研究所程度的選擇題，考的是知識，答案對錯可以直接判定）上，不公開權重的模型最高分 94.6 分，權重有公開的模型最高 93.5 分，只差 1.1 分。如果只看這張考卷，結論會是「差距幾乎消失了」。

但在 SWE-Bench Verified（給模型一個真實的程式庫和一張 bug 單，看它能不能改好並通過測試）上，同樣兩邊的差距是 14.4 分，是前者的十倍以上。這張考卷要的不是知識，而是連續多步驟的規劃、工具操作與自我檢查——這正是把 AI 接進實際作業流程時最需要的能力。

兩個數字都是事實，差別只在引用了哪一張。對我們的實務意義是：選型不要問「哪一顆模型比較強」，要先確定自己要做的事情長什麼形狀，再去找對應的考卷。如果要做的是文件問答與知識查詢，差距確實不大；如果要做的是多步驟的流程自動化，差距目前仍然明顯。

一句話：別人引用的榜單，決定了他給你的結論，所以要問的是「這是哪一張考卷」。

供應商簡報上的「我們接近 GPT-5.6」通常是真的，只是挑了對自己有利的那一張考卷。 實務上的處理方式很單純：把自己實際要做的十到二十件事寫成一份題組，換模型時跑同一份，比較的是同一件事。 這份題組同時也是日後跟稽核解釋「為什麼選這一顆」的依據。

05

證據三：開放與不開放的分界，在同一家公司的產品線裡

不是中國開源、美國閉源，而是每家都留一手

第三個要檢查的是「中國公司開源、美國公司閉源」這個印象。把九家公司各自最強的一顆模型排在同一條軸上之後，這個印象並不成立：能力前 6 名裡有 3 家中國公司，其中兩家最強的那一顆是不公開的。

真正的分界線不在國界，而在同一家公司的產品線內部：對外釋出權重的是次一階的版本，能力最高的那一顆留在自家 API 上收錢。阿里巴巴 2026-08-12 的做法是最清楚的例子——開放權重版是純文字版，拿掉了看圖的能力與 100 萬字的脈絡長度，而且改用自訂授權；同時上架的託管版 Qwen3.8 Max 仍然不公開，能力分數 58.08，高於開放版的 57.70。

月之暗面的 Kimi K3 是另一種做法：權重在託管版上線 11 天之後才釋出，而且授權條款設了兩道門檻——月活躍用戶超過一億、或月營收超過 2,000 萬美元的使用者，必須標示模型來源；拿它去轉售推論服務、且 12 個月營收超過 2,000 萬美元的，必須另外簽商業協議。這代表權重「免費」只對小型使用者成立，規模一大就回到商業談判桌上。

把同一家公司四個世代的授權條件排成時間軸，方向更明顯：前三代都是可自由商用的寬鬆授權，最新一代改成附帶商業條件的自訂授權。單一廠商的四個資料點不足以推論整個產業，但這是一項可以逐季追蹤、而且變化即時可見的指標。

06

證據四：同樣的能力，最便宜的是美國的不公開模型

「開源比較便宜」在 API 這本帳上不成立

第四個要檢查的是成本。直覺上「權重免費下載」應該比較便宜，但比較價格之前必須先固定能力，否則比到的是不同等級的產品。這裡的做法是：取 GPQA 考到 90 分以上的模型視為同一能力區間，再比每一百萬字輸出的公告價。

結果是：這個區間裡最便宜的是 GPT-5.6 Luna，每一百萬字 1.2 美元，是美國的不公開模型；區間內最貴與最便宜相差約 25 倍。權重有公開的模型分布在中段，並沒有占據最低價的位置。

會這樣的原因並不難理解：權重公開影響的是「自建」這本帳，不是「叫 API」這本帳。自建要算的是機房、加速卡、電力與維運人力，只有在用量夠大、或資料完全不能出公司時才划算；而叫 API 的價格是廠商的定價策略決定的，跟模型開不開放沒有關係。近期各家的降價，主要來自搶市占，而不是來自開源。

實務上要小心的是限時優惠。目前低價階的報價多半帶有促銷性質，一旦優惠到期或改成尖峰／離峰計價，同一份工作的成本就會跳動。DeepSeek 已於 2026-08-16 起改為尖峰／離峰計價，就是這類變動的例子。編列預算時應以「原價」估算，把優惠視為一次性的節省。

07

證據五：兩張金融考卷，排出幾乎不相干的名次

這一節決定了「該不該相信排行榜」

前面四節都在引用排行榜。第五節要檢查的是這些排行榜本身有多可靠——這對我們最重要，因為選型會議上被拿出來的，通常就是這類榜單的截圖。

取兩份都與金融有關的考卷做對照。A 榜是 llm-stats 金融榜，做法是蒐集各家自己公布的成績，再用一套統計方法推估名次（TrueSkill，並顯示保守值；公布得少的模型會被系統性壓低）；B 榜是 τ³-Banking，由 Sierra Research 出題、Artificial Analysis 獨立施測，考的是多輪的銀行客服任務——查帳、改資料、處理例外，中間不能出錯。

在 62 個兩榜都有成績的模型上比較名次，等級相關只有 0.34。前十名裡的中國模型佔比，A 榜是 7/10，B 榜是 1/10。同一批模型、同樣叫「金融」，兩張榜幾乎排出不相干的順序。

第二件要一起看的事是絕對水準。B 榜共 169 個模型有成績，最高分只有 51.3 分，而且沒有任何一顆超過 60 分。這代表的不是「哪一顆比較好」，而是目前沒有任何模型能穩定完成這一類多輪銀行任務。把它放進流程時，仍然必須設計人工覆核與失敗處理，不能因為榜單名次高就跳過。

那他們到底靠什麼收錢

九家公司的收入來源，每條都附查證連結

回到最初的問題：如果權重免費送，錢從哪裡來？把九家公司的公開資料整理起來之後，答案相當一致——沒有任何一家靠賣權重賺錢。收入來自三條路，權重的角色是把開發者先吸引進來的入口。

路線一 · 雲服務
模型免費，算力收費

權重放出去讓大家熟悉，真正要跑得穩、跑得快，還是回到自家雲上租機器。 阿里巴巴、字節跳動、百度、Google 都屬於這一類。

阿里雲智慧集團 FY2026 營收人民幣 1,581 億元、年增 34%，是這條路線最具規模的案例。

路線二 · 私有化部署
賣「裝進你家機房」這件事

國企、政府與金融機構的資料不能外送，需要有人把模型裝進自家機房、調校、維運。 權重公開反而讓這門生意更好做。智譜是代表。

智譜 2025 年營收約人民幣 7.24 億元、年增約 132%，客戶集中在國企、政府與金融機構。

路線三 · 授權金
小用戶免費，大用戶另談

授權條款裡設營收或用戶數門檻，跨過門檻就必須標示來源或另簽商業協議。 月之暗面的 Kimi K3 是最新的例子。

月之暗面 2026 年 6 月的年化經常性收入約 3 億美元，其中 API 授權占逾七成。

「公開程度」的八個面向是哪八個

Artificial Analysis 不採開源／閉源的二分法，而是把一個模型的公開程度拆成八個面向分別評分，再彙總為 0 到 88.9 分的指數。八個面向是：

權重相關
  • 權重取得：能不能下載
  • 權重授權：下載之後可以拿來做什麼，商用有沒有條件
資料相關
  • 預訓練資料：有沒有公開用了哪些語料
  • 預訓練資料授權：那些語料本身可不可以被再使用
  • 後訓練資料：調教階段用的資料有沒有公開
  • 後訓練資料授權：同上，可否再使用
方法相關
  • 方法揭露：訓練流程講得多細
  • 方法授權：講出來的方法能不能被他人使用

為什麼要拆這麼細

因為八項裡只要開了第一項，對外就可以宣稱「開源」。本篇第 3 節顯示：目前能力進入前段的模型，幾乎都只開了前兩項。

兩張榜為什麼不能直接比分數

本篇引用的兩個資料源，計分方式完全不同，因此只能比名次、不能比分數。

llm-stats（A 榜）

做法是蒐集各家自行公布的成績，再用 TrueSkill 這套評等方法推估實力，並顯示保守值（μ−3σ，可以理解為「至少有這個水準」的下限）。副作用是：公布得少的模型會被系統性壓低，因為資料不足時保守值會拉得更低。

Artificial Analysis（B 榜）

做法是自己出題、自己施測，同一套九份考卷跑過所有模型後取平均，沒受測的就是沒有分數。τ³-Banking 這一份由 Sierra Research 出題，考的是多輪銀行客服任務。

一句話

A 榜是「彙整別人的自評」，B 榜是「自己重考一次」。兩者的分數放在同一張表上並排，只是為了對照名次，數值本身沒有可比性。
